You maintain the asset pipeline for the Ironhold sci-fi FPS demo. Your job is to run and update Python scripts, manage the asset catalog, and keep GLTF files consistent.

**Rule**: use Python scripts for bulk/repeated changes; direct RON edits only for one-off additions.

---

## Script inventory

All scripts are in `scripts/` and run from the repo root:

| Script | Purpose | When to run |
|--------|---------|------------|
| `update_lib.py` | Download latest `pkg/` and `docs/` from ironhold-lib at the pinned SHA | When updating the engine |
| `update_lib.py --dry-run` | Show what would change without downloading | Before updating |
| `update_lib.py --no-docs` | Skip docs download | Slow connection |
| `check_lib_version.py` | Compare pinned SHA vs latest `main` | To see if engine updates are available |
| `scan_gltf_metadata.py` | Scan all GLTF POSITION accessors → `assets/models/model_metadata.json` | After adding new GLTF models |
| `fix_gltf_texture_paths.py` | Rewrite bare texture URIs in GLTF files to `../../textures/<name>` | After adding new GLTF models |
| `generate_showcase.py` | Regenerate `assets.ron`, `prefabs.ron`, `showcase.scene.ron` from all models | After adding models or changing layout |
| `scan_gltf_textures.py` | Report which texture URIs in GLTF files exist vs. missing | Debugging texture issues |

Run order when adding new models:
```
python scripts/fix_gltf_texture_paths.py   # fix texture URIs first
python scripts/scan_gltf_metadata.py       # compute bounding boxes
python scripts/generate_showcase.py        # regenerate RON files
```

## Engine library update

```bash
python scripts/update_lib.py
# then commit:
# git add pkg/ ironhold-lib.json
# git commit -m "Update ironhold-lib to <sha>"
```

The script fetches `pkg/` files and `docs/` from GitHub at the pinned commit SHA.
`docs/` is gitignored — it is a local offline cache, never committed.
`ironhold-lib.json` tracks `commit` and `previous_commit` SHAs.

## Asset catalog structure (`assets.ron`)

`schema_version: 1`. All paths are relative to `assets/`. GLTF models always need `#Scene0` suffix.

```ron
(
    schema_version: 1,
    models: {
        "alien_cyclop": ( path: "models/Aliens/Alien_Cyclop.gltf#Scene0" ),
        "prop_crate":   ( path: "models/Props/Prop_Crate.gltf#Scene0" ),
    },
    textures: {
        "t_trim_01": "textures/T_Trim_01_Albedo.png",
    },
    audio: {
        "click":    ( path: "audio/menu-click.wav" ),
        "bg_music": ( path: "audio/theme.ogg", volume: 0.6 ),
    },
    effects: {},
    materials: {},
)
```

When adding a model manually (not via `generate_showcase.py`):
1. Add the `models/Category/Name.gltf#Scene0` entry to `assets.ron`.
2. Add the corresponding `Prop` prefab to `prefabs.ron`.
3. Reference the prefab in the scene.

## GLTF texture path convention

Textures live in `assets/textures/`. GLTF models live in `assets/models/Category/`. Bevy resolves GLTF relative URIs from the GLTF file's directory, so the correct relative path from a GLTF file to a texture is:

```
../../textures/T_Trim_01_Albedo.png
```

`fix_gltf_texture_paths.py` rewrites bare filenames (e.g. `T_Trim_01_Albedo.png`) to `../../textures/T_Trim_01_Albedo.png`. Run it on any new batch of GLTF files. Safe to run multiple times — it skips URIs that already have the correct prefix.

To verify: `python scripts/scan_gltf_textures.py` reports broken vs resolved URIs.

## Model metadata (`assets/models/model_metadata.json`)

Generated by `scan_gltf_metadata.py`. Used by `generate_showcase.py` for layout spacing and pivot offsets. Will also be used for physics collider generation.

```json
{
  "_note": "Generated by scripts/scan_gltf_metadata.py",
  "models": {
    "alien_cyclop": {
      "category": "Aliens",
      "gltf_path": "models/Aliens/Alien_Cyclop.gltf",
      "bounds_min": [-0.5357, -1.0906, -0.5782],
      "bounds_max": [ 0.5357,  0.9153,  0.6435],
      "width": 1.0715,
      "height": 2.0059,
      "depth": 1.2217,
      "pivot_y_offset": 1.0906
    }
  }
}
```

`pivot_y_offset = -bounds_min[1]` — how far to raise the model so its lowest mesh point sits at y=0. Add `0.001` in scene placement to prevent z-fighting.

## `generate_showcase.py` configuration

Key constants at the top of the script:

| Constant | Current value | Effect |
|---------|--------------|--------|
| `COLS_PER_ROW` | 10 | Models per row in each category |
| `COL_GAP` | 0.6 | Gap between adjacent model edges (x) |
| `ROW_GAP` | 1.5 | Gap between row footprints (z) |
| `CAT_GAP` | 8.0 | Extra z gap between categories |
| `Y_LIFT` | 0.001 | Base y offset above ground |

Footprint is capped at 5.0 units to prevent outlier models (e.g. `prop_rail_incline_short_r`, 33.5-unit depth) from blowing out the row layout.

## Adding a new model batch

1. Drop `.gltf` and `.bin` files into the correct `assets/models/<Category>/` subfolder.
2. Drop any new textures into `assets/textures/`.
3. Run the pipeline:
   ```bash
   python scripts/fix_gltf_texture_paths.py
   python scripts/scan_gltf_metadata.py
   python scripts/generate_showcase.py
   ```
4. Check the output — `generate_showcase.py` will report entity count and total depth.
5. Stage the new model files, textures, updated RON files, and `model_metadata.json`.

---

## Gitignored paths (do NOT commit)

- `docs/` — local copy fetched by `update_lib.py`; regenerated on demand
- `assets/models/model_metadata.json` is **committed** (it's generated data that should be tracked)
- `.wasm` and `.js` in `pkg/` ARE committed (they are the pinned engine binary)

## Common tasks

**Check if engine update is available:**
```bash
python scripts/check_lib_version.py
```

**Update engine:**
```bash
python scripts/update_lib.py
git add pkg/ ironhold-lib.json
git commit -m "Update ironhold-lib to <sha12>"
```

**Regenerate showcase after adding models:**
```bash
python scripts/fix_gltf_texture_paths.py
python scripts/scan_gltf_metadata.py
python scripts/generate_showcase.py
git add assets/models/ assets/textures/ assets/projects/scifi_fps/assets.ron assets/projects/scifi_fps/prefabs/ assets/projects/scifi_fps/scenes/showcase.scene.ron
```

**Debug a broken texture in a model:**
```bash
python scripts/scan_gltf_textures.py
# look for "NOT FOUND" lines
python scripts/fix_gltf_texture_paths.py
```
